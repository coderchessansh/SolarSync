# SolarSync

SolarSync is a rural solar-powered phone charging solution created as a Social Entrepreneurship project from ODM Public School.

The prototype uses a **6V / 3W solar panel**, **TP4056 charge controller**, **3.7V 18650 rechargeable battery**, **MT3608 boost converter**, and **5V USB output** to store solar energy and make phone charging available when regular electricity is limited or unavailable.

## Website

The SolarSync website presents the project, explains the energy flow, shows a web-ready recreation of the physical prototype, and highlights its social impact.

## Core flow

**Sunlight → Solar panel → TP4056 charge control → 18650 battery → MT3608 boost → 5V USB → Phone**
